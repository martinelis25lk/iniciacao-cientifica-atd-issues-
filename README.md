# Identificação de problemas arquiteturais de software a partir da análise de issues

Iniciação científica (UFPI) sobre o uso de LLMs para identificar issues
que indicam problemas de arquitetura e dívida técnica arquitetural (ATD).

## Orientadores
- Prof. Armando Soares Sousa
- Prof. Pedro de Alcântara

## Objetivo
Investigar como a análise de issues (descrição, comentários e logs),
apoiada por LLMs, pode ajudar a identificar problemas estruturais de
software e ATD, e como eles evoluem ao longo do tempo.
